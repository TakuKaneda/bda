# 📚 Chapter 18: 欠損データモデル (Models for Missing Data)

## Ⅰ. 基礎と表記法 (Notation and Fundamentals)

### 1.1. 基本的な表記法と欠損メカニズム

この章では、意図しない欠損データの問題に焦点を当てます。

- **完全データ ($y$):** 欠損がない場合に観測されるであろうデータ。
- **観測値 ($y_{obs}$):** 実際に観測されたデータ。
- **欠損値 ($y_{mis}$):** 欠損しているデータ ($y = (y_{obs}, y_{mis})$)。
- **包含インジケータ ($I$):** $y$と同じサイズの行列で、各要素が観測された（1）か欠損している（0）かを示す。$I$は常に完全に観測されていると仮定されます。

> **📝 補足: データ収集モデルとの関連**
>
> 欠損データモデルは、チャプター8で議論されたデータ収集と観測に関するモデルの特殊なケースです。
>
> - **項目無回答 (Item Nonresponse):** あるユニット$i$の項目$j$が$I_{ij} = 0$となるケース。
> - **ユニット無回答 (Unit Nonresponse):** あるユニット$i$の全項目$j$が$I_{ij} = 0$となるケース。

### 1.2. 欠損メカニズムの分類

データ収集メカニズム（欠損メカニズム）をモデル化する上で、以下の用語が重要です（チャプター8由来の用語）。

- **MAR (Missing at Random):** 欠損確率が観測されたデータにのみ依存し、欠損データ自体には依存しないこと。
- **MCAR (Missing Completely at Random):** 欠損確率がデータ（観測されたものも欠損しているものも）のいかなる値にも依存しないこと。
- **Ignorability (無視可能性):** ベイジアン推論において、欠損メカニズムのモデル化が不要となる条件。多くの場合、MARがMCARよりも妥当な仮定とされます。

### 1.3. 欠損メカニズムの具体例 (年齢と所得)

ここでは、**多変量データ**における欠損メカニズム（MAR, MCAR, 非無視可能性）を明確に理解するために、具体的な変数の例を使用します。

**設定:**

調査対象者のデータとして、2つの変数があると仮定します。
$$y = (\text{年齢 (age)}, \text{所得 (income)})$$

- **観測状況:** 年齢はすべての人について記録されているが、所得は一部の人について欠損している。
- **モデル仮定:** 簡略化のため、完全データの同時分布は二変量正規分布に従うとモデル化します。

#### A. MCAR (Missing Completely at Random: 完全にランダムな欠損)

MCARは、欠損の確率が、観測されたデータ（年齢）にも、欠損しているデータ（所得）にも、一切依存しない状態を指します。

| 概念 | 詳細なメカニズム |
| :--- | :--- |
| **定義** | **所得が記録される確率**が、年齢および所得の値とは独立である。 |
| **ソース定義** | データは「Missing at Random」かつ「Observed at Random」である。 |
| **結果** | 欠損メカニズムはデータ$y$全体から完全に独立しています。|

#### B. MAR (Missing at Random: ランダムな欠損)

MARは、欠損の確率が、観測されたデータには依存するが、**観測されたデータに条件付けた場合、欠損しているデータ自体には依存しない**状態を指します。

| 概念 | 詳細なメカニズム |
| :--- | :--- |
| **定義** | **所得が欠損する確率**が、回答者の**年齢にのみ依存し**、年齢を与えられた際の回答者の所得の値には依存しない。 |
| **具体例** | 50歳以上の人は、20代の人よりも所得の質問に答えない傾向があるが、50歳の中で所得が高い人・低い人どちらも、同じ確率で欠損する（年齢が欠損を決定する）。 |
| **無視可能性** | MARであり、かつ欠損メカニズムのパラメータ（$\phi$）がデータモデルのパラメータ（$\theta$）と **分離可能（distinct）** である場合、ベイジアン推論において欠損メカニズムは無視可能 (Ignorable) になります。 |

> 📌 **MARの補足:**
>
> 実際には、MARは「観測されたデータ$y_{obs}$が与えられれば、欠損データ$y_{mis}$に依存しない」という条件です。MCARよりも現実的な仮定とされます。

#### C. 非無視可能な欠損 (Nonignorable Missingness)

非無視可能性とは、欠損の確率が、**欠損しているデータ自身の值に依存している**状態を指します。この場合、欠損メカニズムのモデル化は必須です。

| 概念 | 詳細なメカニズム |
| :--- | :--- |
| **定義** | **所得が欠損する確率**が、年齢層に依存し、**さらにその年齢層内の所得の値にも依存する**（例：高所得者または低所得者が所得の報告を避ける）。 |
| **結果** | データはMARでもObserved at Randomでもない。このメカニズムは非無視可能 (Nonignorable) と呼ばれます。|
| **重要性** | 関心のある推定対象（例：所得の周辺分布）によっては、欠損メカニズムのモデル化が極めて重要になります。|

#### 欠損メカニズムと分析目標の関連性

欠損メカニズムの関連性は、分析の目標によって異なります。

1.**年齢変数のみに関心がある場合:**
    - 所得データ（$y_{\text{income}}$）をすべて破棄し、年齢（$y_{\text{age}}$）に関するモデルを構築すれば、所得の欠損メカニズムは無視可能になります。
2. **所得の周辺分布に関心がある場合:**
    - この場合、所得の欠損メカニズム（特に非無視可能性）は**最重要事項**であり、慎重に検討されなければなりません。

#### ベイジアン推論と無視可能性

欠損データ問題における完全データ ($y$) と指標 ($I$) の同時分布は、$p(y, I|\theta, \phi) = p(y|\theta)p(I|y, \phi)$ と記述されます。

ベイジアン推論において、欠損メカニズムが**無視可能である**ための2つの十分条件は、以下の通りです。

1. **MAR (Missing at Random):** $p(I|y_{obs}, y_{mis}, \phi) = p(I|y_{obs}, \phi)$。欠損確率が$y_{mis}$に依存しない。
2. **パラメータの分離 (Distinct Parameters):** データモデルのパラメータ$\theta$と欠損メカニズムのパラメータ$\phi$が、事前分布において独立である。

これらの条件が満たされれば、事後分布の計算は観測データ$y_{obs}$のみに条件付ければよく、欠損インジケータ$I$やメカニズムパラメータ$\phi$を考慮する必要がなくなります。

## Ⅱ. 多重代入 (Multiple Imputation: MI)

### 2.1. 多重代入の背景と目的

欠損データ問題における目標は、パラメータ $\theta$ の事後分布 $p(\theta|y_{obs})$ を求めることです。これは、欠損値 $y_{mis}$ を周辺化（積分）することで得られます。

$$p(\theta|y_{obs}) = \int p(\theta|y) p(y_{mis}|y_{obs}) dy_{mis} \text{}$$

- **単一代入の限界:** 欠損値を単一の値で補完（単一代入）すると、欠損値 $y_{mis}$ に含まれる**不確実性（uncertainty）**が無視され、結果として推定値の分散（標準誤差）が過小評価される問題があります。
- **MIの目的:** 多重代入は、この $y_{mis}$ に伴う不確実性を適切に組み込むためのフレームワークです。**欠損値の事後予測分布 $p(y_{mis}|y_{obs})$ からサンプリングされた複数の補完データセット**に基づいて完全データの事後分布を近似します。

### 2.2. 計算手法との関連性

多重代入は、EMアルゴリズム（Expectation-Maximization algorithm）と関連しています。

- **EMアルゴリズム:** EMは観測データ $y_{obs}$ に基づくパラメータ $\theta$ の事後分布の**モード**を見つけることを目的とします。E-ステップでは、完全データの対数事後密度を欠損データ $y_{mis}$ について平均化（期待値をとる）します。
- **MIとEMの違い:** EMがモードを推定するのに対し、MIは $y_{mis}$ の分布から**サンプリング**を行うことで、事後分布全体を近似しようとします。
- **モノトーンな欠損パターン:** 変数を順序付けたときに、前の変数よりも後の変数のほうが欠損が多いという単調なパターン（モノトーン欠損パターン）を持つデータでは、計算上のショートカットが利用でき、効率的な欠損値補完（多重代入）が可能になります。

### 2.3. 多重代入の結果の統合（ルービンの統合ルール

$K$個の補完データセット $y_{com}^{(k)}$ を用いて分析を実行し、得られた推定値 $\hat{\theta}_k$ と分散 $\hat{W}_k$ を統合します。

| 推定値 | 計算式 | 意味 |
| :--- | :--- | :--- |
| **統合された推定値** ($\bar{\theta}_K$) | $\frac{1}{K} \sum_{k=1}^K \hat{\theta}_k$ | $K$個の推定値の平均 |
| **内部分散** ($W_K$) | $\frac{1}{K} \sum_{k=1}^K \hat{W}_k$ | 補完ごとの平均分散（観測データに基づく推定精度） |
| **間分散** ($B_K$) | $\frac{1}{K-1} \sum_{k=1}^K (\hat{\theta}_k - \bar{\theta}_K)^2$ | 補完間のばらつき（欠損による不確実性） |
| **全分散** ($T_K$) | $W_K + \frac{K+1}{K} B_K$ | 統合推定量の合計分散 |
| **自由度** (d.f.) | $(K-1) \left( 1 + \frac{K}{K+1} \frac{W_K}{B_K} \right)^2$ | $t$分布に基づく区間推定に利用される近似式 |
